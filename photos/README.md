# Photo Gallery Management

Upload photos directly to these folders on GitHub. They appear on the site automatically — no code changes needed.

## Directory Structure

```
photos/
├── events/
│   ├── proms/         → appears under Events > Proms tab
│   ├── engagements/   → appears under Events > Engagements tab
│   └── weddings/      → appears under Events > Weddings tab
└── storytelling/      → appears under Storytelling gallery
```

## How to Upload Photos

1. Go to the folder on GitHub (e.g. `photos/events/proms/`)
2. Click **Add file → Upload files**
3. Drag and drop your photos (JPG, PNG, WebP supported)
4. Click **Commit changes**
5. The photos appear on the live site within a minute

## Tips

- **File names** can be anything — they won't be shown publicly
- **File size** — keep images under 5 MB each for fast loading; 1–2 MB is ideal
- **Dimensions** — 2000–3000px on the long side is plenty
- **Format** — JPG for photos, PNG for graphics, WebP for best compression
- **Order** — photos are displayed in alphabetical order by filename; prefix with numbers (`01_`, `02_`) to control order

## Logo

Upload the logo PNG to `images/logo.png` (the root `images/` folder).
For the best look on the dark background, provide a version with a **transparent background**.
